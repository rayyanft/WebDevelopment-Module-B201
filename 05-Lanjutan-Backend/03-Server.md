# Persiapan Server Production

Saat website dinamis siap, kamu tidak bisa sekadar menggunakan GitHub Pages (karena GH Pages hanya untuk web statis HTML/CSS/JS).

Konsep yang perlu dipelajari:
1. **Hosting / VPS (Virtual Private Server)**: Menyewa komputer 24 jam untuk menaruh database dan kode backend (misal: AWS, DigitalOcean, Niagahoster).
2. **Domain**: Membeli nama unik seperti `namakamu.com`.
3. **Web Server**: Menggunakan Nginx atau Apache untuk mengarahkan domain ke aplikasi backend kamu.
