# XAMPP & Dasar Server Lokal

Untuk modul lanjutan, kamu perlu software yang bisa menjalankan PHP dan MySQL di laptopmu.
**XAMPP** adalah singkatan dari Cross-Platform (X), Apache (A), MariaDB (M), PHP (P) dan Perl (P).

1. Download XAMPP dan install.
2. Buka XAMPP Control Panel, lalu Start modul **Apache** dan **MySQL**.
3. Simpan file web kamu di folder `htdocs`.
