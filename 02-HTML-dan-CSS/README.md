# 🏗️ Modul 2: HTML & CSS (Inti dari Website)

Di sinilah keajaiban dimulai. Website terdiri dari dua fondasi utama:
1. **HTML (Kerangka):** Menentukan apa isi website-nya (teks, gambar, tombol).
2. **CSS (Baju/Desain):** Menentukan bagaimana tampilannya (warna, posisi, ukuran font).

---

## 🛠️ Langkah 1: Membangun Kerangka dengan HTML
Silakan buka dan baca file 👉 **[`index.html`](./index.html)**.

Di dalam file tersebut, saya sudah menuliskan kode lengkap untuk membuat kerangka portofolio. **Perhatikan tulisan berwarna hijau (komentar) di dalam kodenya**, itu adalah penjelasan fungsi setiap baris kode!

**Hasil yang diharapkan:** 
Jika kamu membuka `index.html` di browsermu sekarang, tampilannya akan **jelek!** Hanya teks hitam putih yang berjejer dari atas ke bawah. Kenapa? Karena kita belum memakaikan "baju" (CSS).

---

## 💅 Langkah 2: Mempercantik dengan CSS
Sekarang, mari kita pakaikan baju. Buka file 👉 **[`style.css`](./style.css)**.

Di dalam file ini, kita mengatur posisi (layout) menggunakan teknik bernama *Flexbox*, memberi warna latar belakang, dan mengatur jarak (margin/padding). Jangan lupa baca komentar penjelasannya di dalam file kodenya.

**Hasil Akhir di Modul 2:**
Jika kamu merefresh browsermu, teks hitam putih tadi sekarang sudah berubah menjadi website portofolio yang rapi, menu navigasinya menyamping, dan memiliki kartu-kartu projek!

▶️ **Sudah rapi kan? Tapi websitenya masih agak kaku. Mari kita beri sedikit animasi di [Modul 3: JavaScript](../03-JavaScript/README.md).**
