# Modul 2: HTML & CSS Dasar 🏗️ & 💅

Di sini kita mulai membuat struktur dan desain portofolio.

- **HTML** (HyperText Markup Language) ibarat kerangka tulang bangunan.
- **CSS** (Cascading Style Sheets) ibarat cat dan interior bangunan.

Buka file `index.html` dan `style.css` di folder ini menggunakan text editor (seperti VS Code) untuk melihat contoh kode boilerplate portofolio!
