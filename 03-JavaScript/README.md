# ⚡ Modul 3: JavaScript (Interaksi)

JavaScript (JS) adalah bahasa pemrograman yang membuat website bisa "berpikir" dan melakukan sesuatu.
- HTML = Mobil (Bentuk fisiknya)
- CSS = Cat Mobil (Warnanya)
- JS = Mesin Mobil (Membuatnya bisa berjalan)

---

## 🛠️ Langkah Praktik
Buka file 👉 **[`script.js`](./script.js)**.

Di sana kita membuat sebuah fitur kecil: **Navbar akan berubah warna menjadi transparan jika pengguna melakukan *scroll* ke bawah.**

Lihat komentar di dalam file tersebut untuk mengetahui bagaimana JavaScript "mendengarkan" perintah scroll dari pengguna dan "meresponnya" dengan mengubah CSS!

**Cobalah sekarang:** Buka file `index.html` mu di browser, lalu scroll ke bawah. Perhatikan perubahan pada menu atas (Navbar)-nya!
