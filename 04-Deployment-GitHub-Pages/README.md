# Modul 4: Deployment dengan GitHub Pages 🌐

Saatnya meng-online-kan karyamu agar bisa diakses seluruh dunia!

## Langkah-langkah:
1. Buat akun di [GitHub](https://github.com/).
2. Buat repository baru, misalnya dengan nama `portofolio-saya`.
3. Upload file `index.html` dan folder-folder lainnya ke repository tersebut.
4. Pergi ke tab **Settings** di repository.
5. Pilih menu **Pages** di sebelah kiri.
6. Pada bagian **Build and deployment** (Source), pilih branch `main` atau `master`, lalu klik **Save**.
7. Tunggu beberapa menit, dan portofolio kamu akan bisa diakses via URL `https://[username-github].github.io/portofolio-saya`!
