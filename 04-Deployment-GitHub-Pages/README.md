# 🌐 Modul 4: Rilis ke Internet (GitHub Pages)

Kerja bagus! Websitemu sudah jadi. Tapi saat ini website tersebut hanya ada di laptopmu sendiri.
Agar teman, dosen, atau calon bos bisa melihat portofoliomu, kita harus menaruhnya di **Server Internet (Hosting)**. 

Kabar baiknya: Karena website kita statis (hanya HTML, CSS, JS), kita bisa pakai fitur gratis dari GitHub yaitu **GitHub Pages**.

## 🚀 Panduan Step-by-Step Meng-online-kan Portofoliomu:

1. **Siapkan Akun GitHub**
   - Buka [GitHub.com](https://github.com/) dan pastikan kamu sudah login.

2. **Buat Repositori Baru (Tempat Menyimpan Kode)**
   - Klik tombol **"+"** di pojok kanan atas, pilih **"New repository"**.
   - Isi `Repository name` dengan (misalnya): `portofolio-ku`.
   - Pastikan disetting sebagai **Public**.
   - Klik **Create repository**.

3. **Upload Kode Web Kamu**
   - Di halaman repository baru tersebut, cari tulisan *"uploading an existing file"* lalu klik.
   - Seret (drag and drop) file `index.html`, `style.css`, dan folder/file yang sudah kamu kerjakan ke kotak yang disediakan.
   - **SANGAT PENTING:** Pastikan file utamamu bernama `index.html` (huruf kecil semua), jika tidak, GitHub tidak bisa mendeteksinya!
   - Klik tombol hijau **Commit changes**.

4. **Aktifkan GitHub Pages (Proses Hosting)**
   - Di repository kamu, klik tab ⚙️ **Settings** (Pengaturan) di deretan menu atas.
   - Di menu sebelah kiri, scroll ke bawah dan cari menu **Pages**.
   - Pada bagian **Build and deployment** -> **Source**, biarkan *Deploy from a branch*.
   - Di bagian **Branch**, klik *None* lalu ubah menjadi **main** (atau **master**).
   - Klik tombol **Save**.

5. **Tunggu dan Cek Websitemu!**
   - Tunggu sekitar 1-3 menit (GitHub sedang meracik websitemu).
   - Refresh halaman *Pages* tersebut. Kamu akan melihat notifikasi:
     *"Your site is live at `https://[username-github-kamu].github.io/portofolio-ku/`"*
   
🎉 **SELAMAT! Karyamu sekarang sudah online dan bisa diakses seluruh dunia! Bagikan link tersebut ke teman-temanmu.**
